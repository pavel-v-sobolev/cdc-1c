# Иконки кнопок обработки cdc-1c

Картинки для командных кнопок формы внешней обработки `cdc-1c.epf`.

Назначаются кнопке в конфигураторе: свойство **Картинка** → «Очистить» → выбрать
источник **«Из файла»** → указать png. Тогда картинка хранится внутри `.epf` и не
зависит от конфигурации, в которой обработка запущена. Ссылки на библиотеку
картинок конфигурации использовать нельзя — они хранятся по внутреннему
идентификатору и в чужой базе не разрешаются (иконки исчезают).

## Соответствие кнопок и файлов

| Кнопка на форме | Файл | Смысл иконки |
|---|---|---|
| `Обновить` | `refresh-16.png` | круговая стрелка |
| `ВключитьПланИЕгоОбъктыВODATA` | `odata-16.png` | глобус — публикация в веб-интерфейс OData |
| `ИнициализироватьВыгрузкуВсехОбъектов` | `init-16.png` | молния — стартовая регистрация |
| `ПолнаяВыгрузкаОбъекта` | `upload-object-16.png` | один лист + зелёная стрелка вверх |
| `ПолнаяВыгрузкаВсехОбъектов` | `upload-all-16.png` | стопка листов + зелёная стрелка вверх |
| `ОчиститьИзмененияОбъекта` | `clear-object-16.png` | один лист + красный крест |
| `ПолнаяОчисткаВсехИзменений` | `clear-all-16.png` | стопка листов + красный крест |

Логика набора: цвет отвечает за действие (зелёный — выгрузка, красный — очистка,
синий — чтение/служебное), количество листов — за область (один объект или все).

## Размеры

Для каждой иконки лежат `-16`, `-32` и `-64`. Для командной панели берите **16 px**.
32 и 64 — на случай интерфейсного масштабирования и для документации.

Вариант 16 px нарисован отдельно, упрощённо (толще контур, два листа вместо трёх) —
иначе на таком размере детали сливаются.

## Перерисовать
